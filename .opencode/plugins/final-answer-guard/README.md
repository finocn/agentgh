# final-answer-guard

Плагин-«сторож» для OpenCode. Лечит «тихие» финалы модели
`packet/nvidia-deepseek-v4-1-flash-nvfp4`: она иногда завершает ход
(`finish: "stop"`) и оставляет финальный ответ в канале рассуждений, так что в
сообщении нет части `text`, а ход считается штатно завершённым
(`idle outcome: "succeeded"`). OpenCode такое не повторяет — для него это
не ошибка провайдера, а «успешный», просто пустой ответ.

## Как работает

1. Подписка на `session.execution.succeeded` — это событие в OpenCode 2.4.2
   завершает ход. Важно: перечисленное в схеме API событие `session.idle` на
   практике **не приходит**, на нём сторож молчит.
2. Читаем `ctx.session.context({ sessionID })`, берём последнее
   assistant-сообщение.
3. Если `finish` = `stop` или `length`, нет непустой части `text`, нет
   незавершённого `tool` и нет `error` — это «тихий» финал. После паузы
   `NUDGE_DELAY_MS` (2 с) отправляем в ту же сессию промпт с просьбой выдать
   видимый итог.
4. Когда итог получен, после паузы `CONTINUE_DELAY_MS` (2 с) автоматически
   отправляем промпт-продолжение: выполнить пункт «4) Что дальше», если там нет
   прямого вопроса к пользователю; если вопрос есть — остановиться.
5. **Ограничение цикла:** не больше `MAX_ITERATIONS` (8) автопродолжений подряд.
   На исчерпании лимита отправляем промпт с принудительным завершением и дальше
   молчим, пока пользователь не напишет своё сообщение.
6. Если пользователь написал что-то своё, серия автопродолжений сбрасывается.
   Состояние — в памяти процесса, на диск ничего не пишется.

## Установка

- **В проект:** `.opencode/plugins/final-answer-guard/` загружается
  автоматически.
- **Глобально (во все папки):** держите одну копию и подключите её в
  `~/.config/opencode/opencode.jsonc`, чтобы не было дублей по `id`:

  ```jsonc
  {
    "$schema": "https://opencode.ai/config.json",
    "plugins": ["/абсолютный/путь/к/.opencode/plugins/final-answer-guard"]
  }
  ```

  OpenCode дедуплицирует плагины по `id`: две копии (`~/.config/.../plugins/` и
  `.opencode/plugins/`) дают `Duplicate plugin ID` и одна из них падает.

## Проверка

```sh
node logic.test.ts
```

Логика детектора и решений вынесена в `logic.ts` и не зависит от OpenCode,
поэтому тесты идут обычным Node (24+ исполняет TypeScript напрямую).
